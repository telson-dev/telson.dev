更新日志

从 v0.1.0 到 v0.2.22：40 个工具、300+ 项测试，持续迭代。

完整记录见 GitHub CHANGELOG；这里只列对使用者有影响的变更。

回到项目页 GitHub 完整记录 ↗

v0.2.22 2026-11-09

  • `list_schedules` 定时任务查看工具（第 40 个）：列出服务器在面板里配置的计划任务——cron 表达式、是否启用、仅在线时执行、上次/下次运行时间、每任务步骤数。只读，回答「自动重启配好了吗」「这个服有哪些定时任务」。
  • `pteropilot-alerts --test` 通道自检：发一条测试消息验证 webhook/邮件配置是否正确（不读服务器、不写状态），失败时列出常见原因并以退出码 1 返回（便于脚本判断）。配置告警时先跑它，别等真崩服才发现没收到。
  • Windows 一键装告警计划任务：`scripts/install_alerts_task.ps1`——一条命令建计划任务（默认每 5 分钟），自动生成包装脚本（面板凭据写进去，后台运行不依赖环境变量；中文日志 UTF-8 正常）、日志落 `~/.pteropilot/alerts.log`，支持 `-Status` / `-Remove` / `-DryRun` / `-Exe` 与邮件通道。解决 README 只有 cron 示例、Windows 服主不会配的问题。

v0.2.21 2026-11-08

  • 新增 get_server_activity 操作审计日志：查谁在什么时候重启了服务器、删了哪个文件、建了备份（面板事件流，系统/计划任务触发会标注）——第 39 个工具
  • 参数 limit 1-100（默认 20 条），只读不改任何设置

v0.2.20 2026-11-07

  • 文档口径补全（endpoint 矩阵 / 路线图），无新功能（与 v0.2.19 功能一致）

v0.2.19 2026-11-07

  • 新增 list_databases 数据库查看：面板里已分配的数据库主机/库名/用户名/来源限制（配 LuckPerms、CoreProtect 等 MySQL 插件时直接用）——第 38 个工具
  • 说明：数据库密码不在面板 API 返回范围内，工具会提示去面板网页端查看

v0.2.18 2026-11-07

  • 告警命令 pteropilot-alerts 增强：--dry-run 演练（只打印将通知谁，不发送）、--json 机器可读输出（便于 cron/监控脚本解析）
  • 面板不可达/密钥错误时不再抛一堆堆栈，改为输出可读错误原因

v0.2.17 2026-11-07

  • 新增 get_server_network 网络分配查看：服务器 IP/端口（主地址 ⭐ 标记、附加端口、备注，支持 ip_alias 域名）——第 37 个工具

v0.2.16 2026-11-06

  • 写操作批量工具 batch_power / batch_backup 支持「全部服务器」通配：作用于全部服务器时任何电源信号都强制二次确认（防误操作）

v0.2.15 2026-11-06

  • 批量读工具 batch_list_players / batch_get_console_log 支持「全部服务器」通配——查所有服的在线玩家/日志一句话搞定

v0.2.14 2026-11-05

  • batch_get_status 并发化：多台服务器状态并发拉取（保序、单台失败不阻断）

v0.2.13 2026-11-05

  • 新增 check_panel_connection 连接诊断：验证地址/密钥，401/403/404 给出可操作提示

v0.2.12 2026-11-05

  • 新增 search_server_logs 日志搜索：关键字搜索（不区分大小写、带行号、末尾 5000 行）

v0.2.11 2026-11-05
