v0.2.34 2026-11-16

  • CLI `pteropilot --players [标识] [--days N] [--top N] [--json]`：命令行看玩家活跃趋势
  • CLI `pteropilot --log <标识> [--lines N] [--grep 关键字] [--json]`：命令行看控制台日志
  • `--status --watch [--interval N]`：轮询状态，**只在真的变化时刷屏**
  • `--status --backups [--backup-days N]`：多一列「最新备份」，并把过期的单独点名
  • CLI `pteropilot --help` / `-h`：命令行速查，**不依赖面板配置**
  • `pteropilot-alerts --backup-days N`：备份过期主动推送（合成状态 `stale_backup`）
  • 三个阈值（`cpu_threshold` / `memory_threshold` / `backup_days`）支持在
  • `--doctor` 会对比 GitHub 最新 release，落后时给出可直接复制的升级命令
  • 静态检查：引入 ruff，只开「会变成 bug 的」规则（未定义名 / 未使用导入与变量等），
  • 批量工具加**并发上限**（默认 8，`PTEROPILOT_CONCURRENCY` 可调，夹在 1–32）（Changed）
  • 只读请求遇 429 / 502 / 503 / 504 或连接错误时**自动退避重试**（默认额外 2 次）（Changed）
  • `alerts.py` 用了 `sys.stderr` 却从未 `import sys`——`--reset` 删除状态文件失败时（Fixed）
  • `server.py` 的 `import re` 只写在三个函数内部，模块顶层没有——`--log` 一跑到（Fixed）
  • `--in nan` / `--in inf` 会让 `time.sleep()` 抛未捕获异常：`float("nan")` 是合法的，（Fixed）
  • `--doctor` 的版本行与 `--version` 措辞不统一（同一次输出里「45 个 MCP 工具」和（Fixed）
  • 测试从 545 涨到 782，覆盖率 96.6%（CI 门槛 90%）（Notes）
  • PyPI 上的包仍停在 0.2.0（账号找回中，见 issue pypi/support#12940）；（Notes）

v0.2.33 2026-11-15

  • pteropilot --status [标识]：不开 MCP 客户端直接看服务器状态。不给标识时列出全部（并发拉取）——状态、健康度、CPU、内存；单台失败显示 ⚠ 且不盖住其余服务器；给标识时额外读一次日志推断在线玩家数（拿不到就显示 -，不编数字）。--json 输出结构化结果。退出码：全部健康才 0，否则 1——可直接当 cron 健康检查。
  • 修复 test_cooldown_expiry_notifies_again 偶发失败：冷却正好 60 分钟，而测试把状态时间设成「正好 3600 秒前」，卡在边界上，一次浮点误差或几毫秒调度延迟就能让 elapsed < 3600 翻转。改成 7200 秒，测的还是「过期会再推」这件事本身。

v0.2.32 2026-11-15

  • pteropilot-alerts --cpu / --memory ：资源阈值告警。此前只看「服务器还在不在线」——一台 running 但 CPU 打满、内存快爆的服务器不会叫。CPU 用绝对值百分比；内存用使用率（memory_bytes / memory_limit），面板不限额的服务器自动跳过该项，而不是拿 0 当分母算出假百分比。等于阈值即告警（运维习惯是「到 85 就叫」）。状态正常但资源超限时告警里的状态记为 high_load——否则标题会写成「状态异常（running）」，读起来自相矛盾。默认 0 = 关闭。

v0.2.31 2026-11-15

  • CLI --in / --at：让 --broadcast / --power 等到点再执行。--in 5m / --in 300 / --in 2h / --in 1d（省略单位当秒）；--at 03:00 取下一个该时刻，已过则顺延到明天。等待上限 24 小时（更长的请交给 cron / systemd，别让进程干等）。等待期间 Ctrl+C 取消，退出码 4，一个字都不会发。--in 与 --at 同时给算用法错误（不猜用户想哪个）。

v0.2.30 2026-11-15

  • CLI pteropilot --power --servers a,b：批量电源信号后退出，与 batch_power 工具共用同一份结构化逻辑。--servers 必填——电源是写操作，不替用户猜范围。stop / restart / kill 与 "*"（全部服务器）都必须 --confirm；作用于全部时连 start 也要确认，防一次手滑把全站启动。支持 --json。

v0.2.29 2026-11-15

  • broadcast_command 广播指令（第 45 个工具）：给多台服务器同时发同一条控制台指令——维护前统一通知、统一刷白名单、统一改游戏规则。面板只有单台 /command 端点，这里逐台并发调用。不传 server_ids 时只发给 running 的服务器（停机的发了也收不到），传 ["*"] 才含停机的。高危指令二次确认：stop / kill / op / ban / whitelist off / difficulty peaceful 必须 confirm=True——一条 op 误发会同时作用于所有服。只读模式整体拒绝；单台失败单独标注、不阻断其余。
  • CLI pteropilot --broadcast "指令"：不启动 MCP server，直接广播一次后退出——给 cron / 计划任务用（维护前定时通知不必先起客户端）。支持 --servers a,b 选服、--confirm 确认高危指令、--json 结构化输出；退出码 0 全部发出 / 1 有失败 / 2 用法错误 / 3 被拦截。

v0.2.28 2026-11-15

  • player_stats 玩家在线历史统计（第 44 个工具）：每次 list_players 时顺带记录一次采样，长期积累后按天给出峰值 / 均值 / 采样数——面板本身不提供历史数据，「这个服一般几个人在线」以前只能靠记。采样写入 ~/.pteropilot/playerlog/.jsonl，玩家集合没变时不重复记录，文件超 20000 行自动裁剪只留最近的。list_players 在记录成功后追加一行提示，让用户知道有历史在积累。

v0.2.27 2026-11-12

  • `pteropilot --doctor` 环境自检：检查 Python 版本、面板配置、地址规范化（带 `/api` 会提示已剥掉）、密钥前缀角色（`ptla_` 用错会指出）、面板连通（401/403/404 分别给出含义与修法）、告警渠道；输出**不含密钥**，可整段贴给他人排查。配套 `--no-network` 只查配置不联网
  • `list_mounts` 挂载点查看工具（第 43 个）：列出服务器的额外存储挂载——名称、`source → target` 路径、只读/可写、是否用户可自行挂载。排查「我上传的文件怎么看不到」（挂载没配或只读）。只读。
  • **告警推送失败不再伪装成「查询失败」**：webhook/邮件发送失败时单独归入 `send_failed` / `send_errors`，输出醒目警告并让进程**退出码 3**（此前混在查询错误里、退出码仍 0——服务器真挂了、告警又没发出去时，用户会以为有监控实际没人收到，属最危险的静默失败）；一条都没发出时也不推进冷却状态，下次扫描会重试（Fixed）
  • `pteropilot-alerts --reset`：清空冷却/连续确认状态（调完灵敏度想立刻验证、或服务器已修好但还卡在冷却期时用）；只动状态文件、不碰按服务器配置，支持 `--dry-run` 与 `--json`
  • 发布脚本（`scripts/release.py`、`scripts/sync_release_notes.py`）的 GitHub API 调用加入**指数退避重试**：网络抖动（RemoteDisconnected / 超时 / 连接错误）自动重试 3 次，HTTP 4xx/5xx 仍立即失败——曾因一次连接中断导致打 tag 半途失败（Changed）

v0.2.26 2026-11-11

  • pteropilot --version 在工具数明显偏少（<30）时额外提示「可能装到了旧版本（PyPI 发布可能滞后）」，避免用户以为功能缺失（Changed）
  • README 安装章节：补国内 PyPI 镜像（清华源）命令与 --version 自检方法；把国内常不可用的 git+GitHub 安装方式换成 GitHub Release 下载 .whl，并明确说明本项目不提供代理方案（Changed）
  • 面板地址自动规范化：PANEL_URL 填成 https://panel.example.com/api（面板文档常见写法）时，原来会拼出 /api/api/client → 404，看着像密钥错；现在自动剥掉 /api、/api/client、/api/application 后缀与尾斜杠，真实子路径（如 /pterodactyl）保持不变。（Fixed）

v0.2.22 2026-11-09
