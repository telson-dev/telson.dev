02 · 视频管线

30 秒产品宣传片

整支片子由代码生成：1080P60、1800 帧、分镜与动效全部写成确定性函数， 配乐用纯代码合成（126 BPM，drop 精确落在第 10 秒），全程没有剪辑软件、没有素材库、没有版权风险。

技术做法

  • 确定性动画：单个 HTML 画布，seek(t) 由秒数推导全部画面
  • 帧级渲染：无头 Chrome 逐帧截图 → ffmpeg 编码，可重跑、可复现
  • 代码合成配乐：纯 Python 标准库生成，节拍与画面共用同一组常量
  • 程序化质检：像素探针检查品牌色、文本边界 lint、60 点亮度扫描

参数

  • 1920×1080 · 60fps · H.264 / AAC
  • 时长 30.000 秒，126 BPM，drop @10s
  • 品牌色：青 #2fd9ff / 紫 #8a5cff
  • 纯音乐 + 屏幕字幕，无配音
