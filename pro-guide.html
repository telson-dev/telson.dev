Pteropilot Pro

从下载到用起来

四步：安装 → 激活 → 连接面板 → 开始管理。卡在哪一步，直接看下面的对应章节或常见问题。

① 安装 ② 激活 ③ 连接面板 常见问题

第 1 步

下载与安装

标准版（安装程序）

约 97MB · Windows 10/11 64 位

双击安装 → 桌面出现快捷方式 → 打开即可。想要托盘常驻、开机自启选这个。

Lite（便携版）

约 32MB · 免安装单文件

下载后直接双击运行。U 盘、临时机器、不想改系统都适合。

下载地址：面包多订单「已购内容」；标准版也可在产品页下载。首次打开若提示「未知发布者」（SmartScreen），点「更多信息 → 仍要运行」——这是未买代码签名证书的常规提示，不是病毒。

第 2 步

激活

粘贴激活码

打开客户端 → 顶部「许可证」卡片 → 把购买得到的激活码整段粘贴（含 PTPRO1- 前缀，别漏字符）→ 点「激活」→ 显示「已激活 · 终身」即成功。

先试用也行

首次打开自带 7 天全功能试用，不激活也能用全部功能。觉得合适再买码激活，试用数据不会丢。

换电脑：先在旧电脑点「解绑本设备」，名额释放后在新电脑粘贴同一个码激活（一份授权最多 2 台设备）。

第 3 步

连接面板

填两个字段

① 面板地址：带 https:// 的完整域名（如 https://panel.example.com），末尾不加斜杠和路径。② API 密钥：在面板「账户 → API 凭据」新建一枚 Client 类型的密钥，复制整串 ptlc_ 开头的值。

点「测试连接」

设置卡片里有「测试连接」按钮：成功会显示可访问的服务器数量；失败会明确提示是密钥问题（401/403）还是地址问题（404/网络不可达），按提示改即可。

只读模式：设置里打开「只读」后，客户端只能看不能改（电源/命令/文件写入全部禁用），适合给别人演示或临时借人用。

第 4 步

开始用

选一台服务器

左侧列表选中服务器 → 右侧显示实时状态（CPU/内存/磁盘/在线玩家，5 秒刷新）。颜色标记异常态，一眼看出哪台不对劲。

常用操作

电源（启动/停止/重启/强杀，危险操作二次确认）、控制台看日志发指令、文件浏览上传、备份（手动 + 自动）、服务器地址与数据库查询、操作审计。

AI 助手

关于卡片里填 AI API key（默认 DeepSeek，也可换其它 OpenAI 兼容端点）→ 打开「AI 助手」面板直接对话：『哪个服内存快满了』『帮我重启 smp 服』，它会自己调面板接口。

云同步与更新

设置里可把配置（面板地址、每服调优、告警）一键备份到云端，换电脑一键恢复；新版本会自动提示更新。

常见问题

卡住了看这里

激活失败 / 提示码无效

① 确认整串码完整粘贴（PTPRO1- 开头很长，别断行、别漏字符）；② 确认复制时没带多余空格；③ 若提示「已被使用/设备数已满」，先在旧设备解绑；④ 仍不行把「复制诊断信息」结果发我。

连接面板 401 / 密钥无效

多半是密钥类型错了：要新建 Client 类型（不是 Application），或用错了别人的密钥。到面板「账户 → API 凭据」重新建一枚再贴。

403 / 角色不对

密钥能连上但权限不够：需要面板账号对该服务器有访问权限（子用户需要被分配服务器）。找面板管理员开权限。

404 / 地址错误

面板地址要填域名根路径：https://panel.example.com（不要加 /api、不要带具体页面路径、末尾不要斜杠）。

连不上面板 / 超时

① 浏览器先试试能不能打开面板；② 面板若挂了 CDN/防护（Cloudflare 等），可能拦程序请求；③ 公司/学校网络可能封非 443 端口或异常 UA，换网络试试。

其他问题

加 QQ 2361034217，把「复制诊断信息」的内容一起发来（不含密钥，可放心发），定位会快很多。
