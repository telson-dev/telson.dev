03 · 视频管线

30 秒产品宣传片

整支片子由代码生成：1080P60、1800 帧、分镜与动效全部写成确定性函数， 配乐用纯代码合成（126 BPM，drop 精确落在第 10 秒），全程没有剪辑软件、没有素材库、没有版权风险。

技术做法

  • 确定性动画：单个 HTML 画布，seek(t) 由秒数推导全部画面
  • 帧级渲染：无头 Chrome 逐帧截图 → ffmpeg 编码，可重跑、可复现
  • 代码合成配乐：纯 Python 标准库生成，节拍与画面共用同一组常量
  • 程序化质检：像素探针检查品牌色、文本边界 lint、60 点亮度扫描

参数

  • 1920×1080 · 60fps · H.264 / AAC
  • 时长 30.000 秒，126 BPM，drop @10s
  • 品牌色：青 #2fd9ff / 紫 #8a5cff
  • 纯音乐 + 屏幕字幕，无配音

05 · 小游戏

我的城市

海中央的一座小岛，大小和形状由地图种子决定。开荒、修路、划住宅商业工业区，通水通电， 让市民和开发商自己把楼盖起来；地不够就填海造陆——只能贴着陆地填，越往深海越贵。

2.5D 等距沙盘，昼夜会真的黑下来、窗户和路灯亮起；1× 速度 5 分钟一天。 经营模式要算账（赤字不能动工），沙盒模式随便造。

Canvas 2D 等距 2.5D 城市经营 种子生成 零依赖
打开游戏 → 看夜景截图 ↗

玩法要点

  • 土地是自然的：草地 / 沙滩 / 林地 / 缓丘，建设前先开荒
  • 你只划区：住宅区会长出低层住宅楼 → 多层公寓 → 高层住宅
  • 配套要跟上：道路必须连到市政厅，缺水缺电的建筑会停摆
  • 海是边界：填海造陆 ¥800 起，每往深海一格 +¥700

技术做法

  • 河道与海岸线用极坐标 + 角向谐波 + 噪声生成，同种子逐字节一致
  • 体块建筑三面分色，地形整层离屏缓存
  • 昼夜用合成图层，静态渐变与投影烘成位图：一帧约 16.5ms
  • 存档走 localStorage，3 个手动槽位 + 自动档
