Pteropilot 使用教程

三步接上你的面板：安装、配置、提问。

Pteropilot 是 MCP server，让 Claude、Cursor 等 AI 助手用自然语言管理 Pterodactyl / Pelican 面板上的游戏服务器。全程不需要写代码。

第 1 步 · 安装

用 uvx 一条命令

需要 Python 3.12+。项目用 uv 管理，一条命令安装并运行：

$ uvx pteropilot

没有 uv？先装 uv（Windows：pip install uv）。也可以 pip install pteropilot 直接安装。

第 2 步 · 配置客户端

把 pteropilot 加进你的 AI 客户端

在 Claude Desktop / Cursor 的 MCP 配置里加一段（面板地址和 API Key 也一起填）：

{ "mcpServers": { "pteropilot": { "command": "uvx", "args": ["pteropilot"], "env": { "PANEL_URL": "https://你的面板地址", "PANEL_API_KEY": "你的面板 API Key", "PANEL_READONLY": "0" } } } }
  • Claude Desktop：编辑 claude_desktop_config.json；Cursor：MCP 面板里添加。
  • PANEL_URL 要带协议（https://）；API Key 用权限最小化的那个（见第 4 步）。
  • 改完配置重启客户端，等 AI 识别到 pteropilot 的 32 个工具。

第 3 步 · 提问

用自然语言干活

「列出我所有服务器和状态」

「smp 服最近一次备份是什么时候？没有就现在建一个」

「往 creative 服上传这个插件并重启」

「看看最近日志有没有崩溃信号」

更多能力：电源控制、控制台指令、文件管理、备份、玩家在线、批量操作、广播公告。完整清单见 pteropilot 项目页。

第 4 步 · 安全建议

先只看，再动手

  • 先设 PANEL_READONLY=1 试用：AI 只能看不能动，确认行为后再开写权限。
  • 给 AI 用权限最小化的 API Key：在面板里创建只含必要权限的 API Key。
  • 危险操作（重启、删文件、覆盖备份）会要求二次确认；写操作走面板 API，Key 不出本机。
