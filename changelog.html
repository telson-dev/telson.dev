更新日志

从 v0.1.0 到 v0.2.14：36 个工具、310+ 项测试，持续迭代。

完整记录见 GitHub CHANGELOG；这里只列对使用者有影响的变更。

回到项目页 GitHub 完整记录 ↗

v0.2.14 2026-11-05

  • batch_get_status 并发化：多台服务器状态并发拉取（保序、单台失败不阻断）

v0.2.13 2026-11-05

  • 新增 check_panel_connection 连接诊断：验证地址/密钥，401/403/404 给出可操作提示

v0.2.12 2026-11-05

  • 新增 search_server_logs 日志搜索：关键字搜索（不区分大小写、带行号、末尾 5000 行）

v0.2.11 2026-11-05

  • batch_backup_status 显示备份总大小 + 多台并发；get_server_status 网络流量人类可读

v0.2.10 2026-11-04

  • list_backups / list_files 大小人类可读（1048576 → 1.0 MB），备份显示创建日期

v0.2.9 2026-11-04

  • get_server_status 显示内存/磁盘上限；在线时长格式化为人类可读（1 天 1 小时 1 分 1 秒）

v0.2.8 2026-11-03

  • 新增 batch_list_players 批量在线玩家；get_server_status 增加在线玩家数（日志推断）

v0.2.7 2026-11-02

  • 新增 get_backup_download（备份下载链接）、get_server_startup（启动命令与变量）、batch_get_console_log（批量日志）
  • list_my_servers 支持 with_status 状态列与 status 过滤（如只看 running）
  • 批量工具并发化：广播/批量电源/批量备份，多台耗时从 N× 降到 ≈1×

v0.2.6 2026-11-02

  • 新增 broadcast_message（批量广播公告）、read_server_logs（日志排查）、player_history_stats（玩家活跃统计）、schedule_restart（公告 + 定时重启）

v0.2.5 2026-10-28

  • 真实面板实测工具 scripts/live_smoke.py（只读端到端探测，不触发写操作）
  • diagnose_crash 扩充：看门狗超时、原生崩溃信号；密钥脱敏加固

v0.2.4 2026-10-28

  • 新增 pteropilot-alerts 崩服告警命令：钉钉/企业微信 webhook + 邮件双通道、冷却去重、连续确认阈值、按服务器配置与路由
  • 新增 batch_backup_status / batch_backup 批量备份；双面板兼容（PANEL_APP_KEY + 密钥角色诊断）

v0.2.3 2026-10-26

  • 新增 diagnose_crash 崩溃诊断（内存不足 / JVM 崩溃 / 反复崩溃循环）与 batch_power 批量电源

v0.2.2 2026-10-24

  • 新增 list_players、check_server_health、batch_get_status；MCP 握手真实版本号；面板错误中文化

v0.2.0 2026-09-30

  • Pelican 兼容性验证；新增 upload_file / download_file / create_folder / rename_file 四个文件工具；修复状态与分页问题

v0.1.0 2026-09-27

  • 首个版本：服务器列表/状态/电源/指令/文件/备份、只读模式、高危二次确认、中英双语 README
